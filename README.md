# 🏠 Aura

A modern and responsive **Interior Design Website** built using **HTML, CSS, and JavaScript**.

---

## 📌 Overview

Aura is a frontend web project designed to showcase elegant interior designs with a clean and modern user interface. The website focuses on user experience, responsive layouts, and visually appealing sections for interior design services.

---

## ✨ Features

- 🏡 Modern and elegant UI
- 📱 Fully Responsive Design
- 🎨 Attractive landing page
- 🖼️ Interior design gallery
- 👤 Login & Signup pages
- 📞 Contact & Support page
- ⚡ Smooth navigation

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

---
